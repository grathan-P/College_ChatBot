# AI-Based Academic Assistant

An LLM-powered academic assistant that answers
student questions using college documents and RAG.

## Technology Stack
- Python
- Streamlit
- Google Gemini
- LangChain
- LangGraph
- FAISS

## Team Modules
1. RAG and document processing
2. LLM and LangChain
3. LangGraph and study planner
4. Streamlit and integration

## Setup

Install dependencies:

pip install -r requirements.txt

Run the application:

streamlit run app.py

## Development

Each team member works on a separate Git branch.
Changes are merged into main through Pull Requests.
